# ADR-001: Elecció de base de dades

## Context

El projecte (E-commerce PokeMerch) necessita una base de dades per a emmagatzemar productes, usuaris i comandes, amb relacions no rígides i un esquema que pugui evolucionar fàcilment. Com que el backend es desenvolupa amb Node.js/Express, prioritzem una base de dades amb bona integració en aquest entorn.

## Decisió

Farem servir MongoDB com a base de dades principal, gestionada via Docker.

Concretament, això es reflecteix a `Docker/docker-compose.yml`:
- Imatge `mongo:latest` amb el contenidor anomenat `mongodb_test`.
- Port exposat `27000:27017` (el port local triat per nosaltres, damunt del port per defecte de MongoDB).
- Variables d'entorn `MONGO_INITDB_ROOT_USERNAME`, `MONGO_INITDB_ROOT_PASSWORD` i `MONGO_INITDB_DATABASE` per configurar l'usuari i la base de dades inicials.
- Volum `mongo_data` muntat a `/data/db` per garantir la persistència de les dades entre reinicis del contenidor.

## Conseqüències

+ Flexibilitat per a nous camps i entitats (esquema menys rígid), ideal per a productes de merxandising amb atributs variables.

+ Bona integració amb Node/Express.

+ Desplegament senzill i reproduïble gràcies a Docker.

- Menys adequat per a consultes molt relacionals.

- Les credencials d'accés estan declarades en clar al `docker-compose.yml` (configuració de test, no apta per a producció).
