# ADR-002: Estructura inicial del projecte (monorepo o repos separats)

## Context

El projecte PokeMerch està format per dues parts independents: el backend (Node.js/Express, MongoDB i Docker) i el frontend (React). Cal decidir si s'ha d'organitzar tot el codi en un únic repositori (monorepo) o en repositoris separats, ja que cada part té cicles de vida, dependències i equips de desplegament propis.

## Decisió

Farem servir repositoris separats per a backend i frontend.

Concretament, això es reflecteix en l'estructura actual del projecte:
- `backend/` és un repositori git independent amb origin a `https://github.com/alguna-jviladoms/backend-PokeMerch.git`.
- `frontend/` és un repositori git independent amb origin a `https://github.com/alguna-jviladoms/frontend-PokeMerch`.
- El directori arrel del projecte no conté cap repositori git propi.

## Conseqüències

+ Independència de versions i cicles de desplegament entre backend i frontend.

+ Control d'accés i permisos granulars per repositori (per exemple, només el backend pot tocar la configuració de la base de dades).

+ Historial de canvis més net i centrat per a cada part.

- Cal coordinar manualment els canvis que travessen backend i frontend (per exemple, canvis en el format de les respostes de l'API).

- Més feina de configuració inicial en cada repositori (CI/CD, variables d'entorn, etc.).
